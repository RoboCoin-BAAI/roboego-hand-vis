# 数据库入口选表

目标：全部 12 个阶段入口及数据库下载支持 `--table`，默认 l1data，保持手动处理流程。

- DataService 保存经白名单校验的表名，阶段领取与写回使用同一表。
- 阶段首次使用时反射真实表结构，检查当前阶段及依赖字段；不自动更改表结构。
- 公共 CLI 函数添加参数并创建经过结构检查的服务；所有数据库入口接入。
- 下载适配器接收表名，直接下载模式不加载数据库依赖。
- 先验证失败测试：所有入口帮助、L2/L3 缺字段拒绝领取、补齐字段后 12 个阶段跨表隔离、下载选表。
- 完成实现后运行全量测试和 PostgreSQL 并发测试；不操作业务数据库，不自动提交推送。
