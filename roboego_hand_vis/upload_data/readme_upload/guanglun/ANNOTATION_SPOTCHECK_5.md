## 逐条判断

1. **简智 70**：擦药盒后放入篮子，再逐个擦拭并上架。物品、动作命名基本合格；`wipe box` 有直接依据，但仅表达清洁，未覆盖上架目标。若采用主要目标规则，需要明确清洁与整理谁优先，当前不能武断判错。
2. **简智 37**：从纸箱取包装盒，放到货架并对齐。两个 `box` 分别来自外层纸箱和包装盒，词汇收敛后区分变弱，但属性和文本仍保留。`prepare` 不在当前 Subtask/Atomic 参考词表中，且“准备放置”不宜作为独立、明确的操作标签。子任务多次出现 `place`，动作总表却缺少它；总述支持 `stack box`，但子任务只有放置与对齐，没有明确上下堆叠证据，需复核，不能仅凭文本确认堆叠。
3. **简智 64**：擦货架和商品盒，并把商品整齐归位。`organize box` 合理，但整体目标也可理解为整理货架，主对象粒度尚未固定。动作词表基本有依据；`ground` 是环境实体而非被操作物，是否留在 objects 应由对象字段范围决定，不属于本轮仅清洗 name 可擅自删除的内容。
4. **光轮 46**：将五类棋类/桌游盒逐一放入柜内，最后关门。`organize box` 合理。动作总表只有 `close, pick`，明确遗漏放置动作 `place`；旧子任务本身也只抽出了 `pick`，本轮仅对原词表做名称清洗无法补齐这一遗漏。五个对象均变为 `box` 符合去修饰策略，但游戏种类只在文本中保留。
5. **光轮 94**：用海绵擦洗手台台面和镜子，再把海绵放回托盘。物品、动词基本合理；`wipe counter` 遗漏占较大篇幅的镜子清洁目标。不建议直接改成 `wipe mirror`，那会反过来丢失台面；需用带定义的任务目录规定多对象清洁如何命名。

## 共性结论

- 名称表面清洗基本达成：这些物品名无量词、颜色、大小修饰，动作没有重复词。
- 语义完整性仍不足：仅规范原词表，不会自动补齐原标注漏抽的动作。
- 相同 `box` 名称不表示同一个实例；不应据此删除或合并 objects 条目。
- 任务名主要问题是主目标、主对象及多目标任务的边界尚未定义，不能仅靠语法校验解决。
- 5 条都缺少 `common_task_name` 字段；光轮两条有旧字段 `common_task`，其值分别为 `organize game`、`clean building surface`，不等同于新大类字段。这里只确认抽中记录的现状，不推断全量完成情况。

建议后续分别检查“词汇合法性”和“相对描述的覆盖度”，建立带定义的任务目录；本次不自动覆盖或补写任何字段。
