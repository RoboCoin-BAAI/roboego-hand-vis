**合并时先使用成功样本索引，或只读取完整结果中 `status=done` 的记录。** 待复核样本仍保留旧任务名，不应因其原名存在就当作已规范完成。

典型归并：普通整段理发 `cut hair`，吹干头发 `dry hair`，多种衣物整理 `organize clothing`，纸张成堆 `stack paper`，标识标签粘贴 `stick label`。动词使用 Subtask 词表；不以 Atomic 动词出现频率决定整段任务。

主物品可以由物品列表或明确的描述文字提供证据。例如描述明确“擦桌子”，即使 `objects` 未单列桌子，也允许 `wipe table`。不把多目标任务强行压成某一个物品；词表不能忠实覆盖的任务保留复核。
